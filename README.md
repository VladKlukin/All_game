#   Три в ряд

Классическая игра "Три в ряд" с двумя увлекательными игровыми режимами. Управляйте фишками, составляйте комбинации и достигайте высоких результатов!

## 🎮 Игровые режимы

### ⏱️ Режим на время
*   Цель: Наберите как можно больше очков до истечения таймера.

### ♟️ Режим на 20 ходов
*   Цель: Выполните целевое количество очков за ограниченное количество ходов (20).


## 🚀  Запуск
Введите:
    g++ game.cpp main.cpp tile.cpp ui.cpp -o start
    ./start


## 🕹️ Как играть

1.  Выберите режим: На главном экране выберите "На время" или "На 20 ходов".
2.  Выберите координату фигуры чтобы поменять её местами с другими.
